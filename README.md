# COMP1589-Week-Lab

Weekly lab exercises and coursework files for COMP1589.

## How to Download This Repository

### Option 1: Clone with Git (recommended)

1. Make sure [Git](https://git-scm.com/downloads) is installed on your computer.
2. Open a terminal and navigate to the folder where you want the project saved.
3. Run:
```bash
   git clone https://github.com/Macy2107/COMP1589-Week-Lab.git
```
4. Move into the project folder:
```bash
   cd COMP1589-Week-Lab
```

### Option 2: Download as ZIP (no Git required)

1. Click the green **Code** button at the top of this repository.
2. Select **Download ZIP**.
3. Extract the ZIP file to your preferred location.

## Repository Structure

- `Lab 8/`, `Lab 9/` — Weekly lab exercises
- `Week 1/`, `Week 6/`, `Week3_lab 2/` — Weekly coursework files
- `lab_start/`, `lab_start 2/` — Lab starter files
- `week2-main/` — Week 2 project files

## Requirements

- A modern web browser (for HTML/CSS files)
- [Git](https://git-scm.com/downloads) (if cloning instead of downloading ZIP)
